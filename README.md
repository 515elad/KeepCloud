# KeepCloud

KeepCloud MVP (product name: KeepAir): visibility and enforceable budgets for AI spend.

**Status:** phase 1 of 6. Budgets, the vendor and model registry and block cascade are visible with demo data. Nothing is enforced yet: the gateway arrives in phase 2.

- Run the demo and find all documents: [docs/README.md](docs/README.md)
- Requirements: [`claude/`](claude/)
