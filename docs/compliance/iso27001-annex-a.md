# ISO/IEC 27001:2022 Annex A mapping (MVP controls)

KeepAir is built to be **aligned with** these controls. This is not a certification, no certification is claimed, and the mapping has not been reviewed by an auditor (PRD v1.5 Section 13).

Status after phase 6, the end of the MVP. "Partly" names what is missing.

| Control | Topic | Status | Code | Test |
|---|---|---|---|---|
| A.5.15 | Access control | Partly: the block decision is a pure function with default deny and vendor-over-model precedence; the UI never shows a state the policy does not hold. Cross-site form posts are refused. The gateway is a separate listener that serves no admin route and refuses every path not on its allowlist; the principal comes from the credential only. Roles are phase 5. | `src/keepair/registry.py`, `src/keepair/gateway/app.py` (`ALLOWED_PATHS`), `src/keepair/gateway/auth.py`, `src/keepair/web/app.py` (`same_origin`) | `tests/unit/test_registry.py`, `tests/integration/test_gateway_bypass.py::test_unlisted_provider_path_denied`, `::test_token_cannot_reach_admin_routes`, `tests/integration/test_gateway_path.py::test_principal_ignores_client_headers`, `tests/system/test_gateway_registry.py::test_cross_site_form_post_is_refused`, `::test_form_posts_as_a_real_browser_sends_them` |
